# Merge Sorted Arrays (TypeScript)

This project implements an efficient algorithm to merge three sorted arrays into a single sorted array (ascending order). The solution is implemented in TypeScript and includes unit tests.

## 📋 Requirements

- **Node.js** (v14 or higher recommended)
- **NPM** (Node Package Manager)

## 🛠️ Setup & Installation

1. **Clone the repository**:
   ```bash
   git clone [https://github.com/teewara192/PreInterview-PRIMO.git](https://github.com/teewara192/PreInterview-PRIMO.git)
   cd PreInterview-PRIMO
   ```
   
2. Install dependencies: Run the following command to install TypeScript, Jest, and other necessary packages defined in package.json.
  ```bash
  npm install
  ```

🚀 How to Execute the Code
To run the main implementation script (located in src/index.ts):
```Bash
npm start
```
Note: You can modify the input arrays in src/index.ts to test different values manually.

🧪 How to Run Unit Tests
This project uses Jest for unit testing. The tests cover various edge cases (empty arrays, negative numbers, duplicates).

To execute the test suite:

```Bash
npm test
```

📂 Project Structure
- src/index.ts: The main logic for the merge function.
- src/index.test.ts: The unit tests ensuring the logic is correct.
- package.json: Project configuration and dependencies.
